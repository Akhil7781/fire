STAGE 8.25
MULTI-YEAR ACUTE-EVENT DATASET + INDUSTRIAL FIRE MINING + INDEPENDENT 4-CLASS BENCHMARK

============================================================
MISSION
============================================================

The current project has a technically complete multimodal architecture, but scientific validation is blocked because the current held-out test contains:

Industrial Fire      = 0
Forest Fire          = 0
Agricultural Fire    = 0
Persistent Source    = supported

The objective of Stage 8.25 is to solve this data problem.

The target is to build a real, independently validated 4-class benchmark capable of evaluating:

1. Industrial Fire
2. Forest Fire
3. Agricultural Fire
4. Other Thermal Source / Persistent Non-Biomass Thermal Source

TARGET PERFORMANCE OBJECTIVE

Aim for:

- accuracy >= 85%
- macro F1 >= 85%
- balanced accuracy >= 85%

IMPORTANT:
These are TARGETS, not guaranteed results.

Do not manipulate the dataset, split, labels, or test set to obtain 85%.

The scientific goal is to discover whether the system can actually reach the target.
