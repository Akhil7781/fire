Architectural & Scientific Principles

  • Zero Retraining / Zero Weights Modification: Frozen checkpoint hash verified on every cold start.
  • Strict Isolation: The 41 causal model features DO NOT include proximity to schools, hospitals, or villages. GIS proximity is strictly post-attribution context.
  • WGS84 Geodesic Distances: All spatial metrics calculated using standard ellipsoidal geodesic formulas (sub-millimeter precision).
  • Zero CARTO: Zero legacy CARTO map tile endpoints in the codebase; 100% Geoapify Places API and vector tiles.
  • Safe Single-Process Scheduler: Automatic 10-minute FIRMS poller uses an async concurrency lock preventing race conditions.
